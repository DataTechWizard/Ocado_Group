# Templates

> Reusable templates for consistent documentation across the vault. Use these when creating new entries in any section.

---

## Available Templates

| Template | Used For | Folder |
|---|---|---|
| [[Template_Memory]] | New memory/context entries | `10_Memory/` |
| [[Template_Bug]] | Bug reports | `40_Bugs/` |
| [[Template_Decision]] | Architecture Decision Records | `50_Decisions/` |
| [[Template_Learning]] | TIL / learning entries | `60_Learnings/` |
| [[Template_Progress_Weekly]] | Weekly progress logs | `30_Progress/` |

---

## How to Use (Obsidian)

1. Install the **Templater** plugin (recommended) or use core Templates plugin
2. Set the template folder to `90_Templates/`
3. When creating a new note, use `Ctrl/Cmd + T` to insert a template
