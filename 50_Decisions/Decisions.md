## ADR Statuses

| Status | Meaning |
|---|---|
| 📝 Proposed | Under discussion, not yet agreed |
| ✅ Accepted | Agreed and in effect |
| ❌ Rejected | Considered and declined |
| 🔄 Superseded | Replaced by a newer ADR |
| ⏸️ Deferred | Parked for later consideration |

---

## How to Use

1. Create a new ADR using [[90_Templates/Template_Decision|the decision template]]
2. Add a row to the log above
3. Tag with `#decision` and relevant domain tags
4. Get agreement from relevant stakeholders before moving to "Accepted"
