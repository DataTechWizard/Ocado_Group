## Project Context (TL;DR)

This vault covers the **Ocado Smart Platform (OSP)** data engineering work, focused on:

- **GA4 implementation** for 15+ global grocery partners (canonical OSP event model)
- **Asda build-out** — greenfield GA4/Firebase/GTM implementation (primary account)
- **Retail media reporting** — `creative_slot`, `item_promotion`, BigQuery exports
- **Governance** — maintaining the canonical measurement contract across partners
- **Legacy migrations** — moving partners off older tracking into the OSP framework
