# Code

> All project code, scripts, schemas, and configurations. Organized by domain.

---

## Structure

| Folder | Contents |
|---|---|
| `schemas/` | GA4 event schemas, OSP canonical model definitions |
| `gtm/` | GTM container exports, custom templates, variables |
| `bigquery/` | SQL queries, scheduled queries, table schemas |
| `firebase/` | Firebase config, app analytics setup |
| `scripts/` | Utility scripts, automation, data validation |
| `tests/` | Test suites, validation scripts |

---

## Conventions

- All SQL files use `.sql` extension with descriptive names
- Schema definitions use JSON Schema format (`.json`)
- GTM container exports follow Google's standard export format
- Scripts include a header comment with purpose, author, and date
- Tests mirror the source folder structure
